## About the project

I built an end-to-end website for a boutique florist in Efeler, Aydın, so customers can browse bouquets and order online. The site is live at `floryaaydin.orhunserbetci.com`.

## Features

**For customers**
- Product catalog by category (bouquets, arrangements, potted plants, opening flowers…)
- Cart and checkout flow, plus ordering via WhatsApp
- Discount codes (minimum total, usage limit, date range)
- Accounts: email/password sign-up, Google/Facebook sign-in, password reset, order history and profile

**Admin panel**
- Add/edit products; photos are resized automatically on upload
- Order status tracking (new → confirmed → preparing → on the way → delivered)
- Discount code management and simple visit/cart statistics

## Technical setup

- **Frontend:** Plain HTML/CSS/JavaScript with no framework, so it loads fast.
- **Supabase:** Database (PostgreSQL), authentication and photo storage. Security relies on **row-level security (RLS)** rules: customers only see their own orders, and admin rights are checked separately in the database.
- **Demo mode:** Without a Supabase connection the site runs on browser storage, so it can be demoed in sales meetings without touching live data.
- **Hosting:** Vercel, on the `floryaaydin.orhunserbetci.com` subdomain.
